# Necessary guards for the author's repeated genuine-notch return programme

This is a physical completeness audit of the proposed GSE01 mechanism, not its existence proof or a competing return-map construction. Author owns the general construction; Fable owns the independent structural route.

## Exact lower-source cap phases

Write beta=H-h>0. After the original source band, let its actual strict h-entry phase be q0=z0 with |z0|<a. For one common slope tau>0, a programme of n>=1 outer-roof cycles has descending h phases

    q_j=q0+2j*beta*tau,  j=1,...,n.

Every intermediate descent must be a GENUINE notch-floor contact:

    a < F_A(q_j) < w, j<n.

The final descent must be the actual right mouth:

    w < F_A(q_n) <= A.

The endpoints a,w are true reflex corners and are excluded. x=A is a smooth ordinary outer-wall contact, so it is not a forbidden true vertex at height h. A left-mouth descent cannot be reflected as though it were a notch floor; it exits this proposed finite programme and would need a separately proved genuine left excursion. An earlier right-mouth descent also exits, so the intermediate notch conditions are FIRST-HIT restrictions, not merely allowed-state labels.

Crucially, EVERY cycle also requires

    q0+(2j-1)*beta*tau NOT in A Z, j=1,...,n.

Those are the TRUE outer-roof corners. They cannot be omitted by inheriting the old single-roof disjoint-mouth proof.

## Why strict notch returns do not protect intermediate roof corners

For ANY strictly interior notch point x in (a,w), set a local upward cap state at (x,h) with tau=(A-x)/beta>0. Its formal roof phase is x+beta*tau=A, a true forbidden corner. Its formal next descending h phase is 2A-x, whose physical fold is x. Thus both endpoint h phases are strictly inside the genuine notch floor, yet the intermediate roof contact is singular.

This is an exact local guard countercontrol for arbitrary geometry, not a qualifying darkpair or a claim that this state is forced from an original source. It shows why strict h endpoint inequalities alone do not imply a legal intermediate cap cycle. Deleting the formal cycle changes the departing horizontal velocity at a notch point. The accepted exact-original-S suffix lemma applies only when its return point is EXACT S with the proved matching state; it does not authorize deletion at an arbitrary notch return.

The very first cycle, with left entry x<a and notch/right exit x>a, cannot have a roof corner because that would return to the same h abscissa. Similarly the final notch-to-right cycle has disjoint endpoint intervals and no roof corner. Intermediate notch-to-notch cycles lack that disjointness; they need the explicit guard above. If n=1 the original single-roof argument is sufficient.

## Actual target remains one coupled equation

At fixed n, put C_n=2n*beta and choose the source duration X and target duration d as in joint-root.md. The exact target root uses

D_n=X+C_n+(h-c)+d,

tau=((2m+1)A+epsilon*z-sigma*s+2a*i+2R*k+2B*j)/D_n.

Strict final source/cap/right windows and the full actual target image remain necessary. The intermediate notch and EVERY-roof guards must be checked at THIS SAME tau, for all j<n. Choosing a cap orbit that eventually exits right and then choosing an unrelated target root would change those phases and would not prove the claimed programme.

For a direct upper/mouth source u>=h the descending h phases are instead

sigma*s+[2j*beta+h-u]*tau,

and roof phases are

sigma*s+[(2j-1)*beta+h-u]*tau.

The first roof time H-u is positive for u<H. Intermediate h contacts and final right exit need the same genuine-wall restrictions. An upper formal roof-corner shortcut must return to EXACT original S; a generic later notch point is insufficient. A downward initial left-excursion programme needs its own first-hit guards and is not silently covered by these upper formulas.

## The universal availability gap

A positive proof must select some FINITE n and one direction jointly with original endpoint equality, all preceding notch-only returns, every intermediate roof exclusion and the final right/corner guards. No cap-period, arithmetic recurrence, open-prefix statement or finite state quotient proves that selection automatically. Conversely, failure of one nominated sequence or this restricted programme does not imply darkness or exhaust all physical rays.
