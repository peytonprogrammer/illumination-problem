# SC01: a legal source branch crossing the full thin gate forces an actual target hit

Status: HAND optical implication and darkness-necessary constraint pending independent review. Uses the still-pending literal safe-target gate proof BD/GT. This is not a universal source-branch availability theorem. Full ordered/r3/r<=8 remains open.

## Domain and actual source prefix

Use the integral ordered room, native S=(s,u), and native/integer T=(t,v) with l<t<w, 0<v<c. Let L=w-t>0, G=h-c, P=2lcm(a,A,A-w,A-l), epsilon in (0,1/(2H)), tau=P+epsilon and z=1/epsilon>2H.

Fix ONE finite actual S-to-h prefix itinerary and source germ, on a connected open z interval J where every reflection and first-hit wall guard is legal, every true corner is avoided, and the final actual cap state is negative/downward in the thin target gate. This is a real original-room trajectory, not a free mouth point or an independently chosen lower-room ray.

Its vertical duration D_S is a positive integer and its cap coordinate is x_S=C-epsilon*D_S for a fixed integer C. This is the whole-word unfolded identity with the ACTUAL negative final horizontal sign. Thus, putting alpha=C-w,

    q_S(z)=z*(x_S(1/z)-w)-G=alpha*z-D_S-G,
    0<q_S(z)<2c.

In particular alpha>0, since D_S+G>0 and z>0. Source and target are fixed throughout; the prefix wall word and source germ are fixed on J. The actual prefix may have arbitrary earlier left/right/bottom returns. If it hits actual T earlier, that is already a legal illuminating prefix and can be truncated.

## SC01a: a quantitative sufficient width

Set M_T=2max(v,c-v), strictly less than 2c. If

    (alpha+L)*length(J) > M_T,

then some z in J gives a literal corner-free actual S-to-T ray by concatenating this prefix with one SAFE pre-left-turn last-bottom tail. It suffices that J contains a subinterval satisfying the same strict width inequality; infinite lengths are not needed. Endpoint equality alone does NOT suffice for an open interval.

Proof. A safe target branch at the cap has normalized gate coordinate

    q_T=2cm+c+sigma*v-L*z,
    sigma in {-1,+1}, m>=0,

with its full strict gate guard 0<q_T<2c. At a common physical state q_S=q_T exactly when

    Theta(z)=(alpha+L)*z-D_S-G
        belongs to Lambda_T={2cm+c-v,2cm+c+v : m integer}.

The two residues c-v,c+v modulo 2c have alternating gaps 2v and 2(c-v), so the largest gap is M_T. Every OPEN real interval of length STRICTLY GREATER than M_T contains a Lambda_T point. Theta maps J to an open interval with length (alpha+L)*length(J), giving the root. A point at the endpoint of J is not admitted.

The root is rational because all coefficients and Lambda_T values are integral. Also Theta=q_S+Lz>2HL>2c, so any matching level has m>=1: no negative return count or unavailable negative-time target branch is used. At the root 0<q_S<2c gives the exact strict bottom gate, and BD's safe kappa=-1 tail is ordinary and corner-free all the way to actual T. Both physical velocity signs match (-tau,-1), with the SAME tau. The prefix is legal by hypothesis. This concatenation is one actual billiard ray, not a splice with independently varied direction or target sheet. Earlier actual T can be truncated.

## SC01b: full-gate crossing is sufficient, with both target-arrival choices

The entire geometrically possible thin-gate z interval for this affine source branch is

    J_gate=((D_S+G)/alpha,(D_S+G+2c)/alpha).

If J_gate is contained in z>2H and that SAME actual source prefix is regular throughout J_gate, then S illuminates T. In fact at least one parameter exists in EACH target-arrival-sign residue class, hence at least two distinct rational slopes exist (earlier-target truncation may change which visit is first).

Indeed length(J_gate)=2c/alpha, so Theta(J_gate) has length 2c*(1+L/alpha)>2c. Each individual residue class c+sigma*v+2cZ has period 2c, and an open interval longer than one period contains an interior member of each class. Distinct signs cannot give the same root since v/c is not an integer. All literal guards are as in SC01a.

This is a sufficient source-side condition which does not assume a continuous selector through the target gate breaks. It neither asserts nor proves that every original room/pair has such a source prefix. A branch cut by an earlier source-corner event or the z>2H boundary may fail the condition.

## SC01c: a necessary source-component constraint under ACTUAL darkness

Suppose the specified actual pair is dark in the full original room. Then EVERY source prefix and regular connected thin-gate component J above must satisfy

    Theta(J) misses Lambda_T,
    length(J) <= M_T/(alpha+L),
    diameter(q_S(J)) <= alpha*M_T/(alpha+L) < M_T < 2c.

Reason: otherwise SC01a constructs an actual ray. Since Theta(J) is connected and misses the discrete target levels, it is contained in one gap between adjacent Lambda_T points. That gap has length at most M_T; multiplying by alpha/(alpha+L) gives the normalized source-span bound. Non-strict bounds allow open components with endpoint limits at target levels. This is a necessary relation under full darkness, not evidence that any room is dark.

Thus actual darkness would force every such source component to be shorter than a full geometric gate sweep. To turn this into a positive theorem one must prove that the original source has a component violating that bound, or another legitimate mechanism supplies a target hit. The current work proves neither. Finite-prefix corner cuts may occur repeatedly at developed images of the SAME physical corner; no injective corner count, finite full-word list, or nine-distinct-corner assertion is justified.
