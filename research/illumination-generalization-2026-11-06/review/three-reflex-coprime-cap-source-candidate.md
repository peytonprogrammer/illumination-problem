# CS01 candidate: begin the one-roof construction inside the cap

This is a new hand-proof candidate in a scope disjoint from the author's CE02 two-sign orbit. No discovery or new room search is proposed. It is not yet independently accepted.

Use CE01's geometry with rational a>0, integer L>=2,N>=L+2,A=Na,w=(N-1)a,l=(N-L)a, and integer0<b<c<h<H. Consider rational actual S=(s,u),T=(t,v), with0<s<a,h<u<H,l<t<A,0<v<c and integral u,v. Put C=2H-u-h and d2=c-v. Claim: gcd(C,N)=gcd(Nd2,L)=1 gives a finite actual corner-free one-roof S-to-T ray.

The source now lies in the actual upper cap. Omit the initial source corridor entirely; cap developed duration is C. Only cap exit and right-to-bottom portal endpoints need excluding. Their distinct event times C and C+h-c are in(0,2H-u-v), so two forbidden classes cannot cover the entire integer initial grid.

Potential whole-native corollary: integer a>=1,L=2^r(r>=1), N odd prime>=L+2, integer cap depth delta=H-h>=1 with2delta<N, arbitrary ordered integer0<b<c<h,c odd. Each native terminal source below h has coprime cap length2delta; one above h has integer C between delta and2delta, hence coprime to N. Native d2 is odd, so gcd(Nd2,L)=1. Protected TR01 supplies the other pair placements. This would cover arbitrary native upper-cap source heights in this family, rather than requiring H=h+1.

Strongest challenge: the source begins above h, so the old two-h-crossing roof-corner exclusion cannot be cited. A new roof-corner argument must use the source position at height u and the reflected cap position at height2H-u, proving their separation before cap exit. If that cannot be proved, the claimed transfer is not yet valid. All remaining finite-wall, local signed-velocity and first-target guards must also be proved directly.
