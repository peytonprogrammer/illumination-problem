# Exact prerequisites for weighted return transfer

Independently hand derived for review. These are conditional transfer lemmas and an arithmetic-rank diagnostic, not a low-reflex existence theorem. No search, new engine or finite direction list is used. All positive integer weights below are unbounded.

## 1. An accelerated return must carry its event itinerary

Let M be the original translation unfolding, with forbidden set Sigma containing every actual polygon-corner lift, including removable corner marks unless separately justified away. Let X,Y be the actual interior source and target lift sets. Fix ONE nonzero developed velocity w. A section point includes its actual sheet/prong; a torus coordinate alone is not its identity.

Suppose R is a genuine first-return map for this same flow, with a positive roof length ell(z). A retained section J may have accelerated map R_J(z)=R^k(z), where z_i=R^i(z), 0<=i<=k, and

    L_J(z)=sum_{i=0}^{k-1} ell(z_i).

This equality is physical time in a fixed w normalization. Every intermediate return must actually exist with the stated first-hit domain; if a forbidden corner occurs before the proposed return, that proposed legal return is undefined. A symbolic permutation extended through that corner is not the physical map.

For a block of length L, retain its full event data

    E_z={(t, actual point/sheet, label): 0<t<=L,
          phi_w^t(z) lies in Sigma union X union Y}.

Events at t=L are included and initial time0 is excluded. At true cone points phi is defined only up to the first hit; a proposed longer symbolic continuation is never used to certify a legal block.

A physically valid accelerated source-to-target itinerary pulls back to a legal original ray if every expanded block is an actual same-w flight, no Sigma event occurs at or before target attainment, its starting point lies in X and its ending point lies in Y. If Y occurs earlier, truncate at its FIRST actual occurrence; earlier X events are legal interior visits. This is sufficiency by concatenating uniquely continued same-w flow with positive travel times. Conversely any original finite legal connection gives such an accelerated description whenever the section representation includes its initial and terminal partial blocks. Without those partial blocks a new section can miss both actual marks.

For EXACT preservation of target reachability, a target visited strictly inside an accelerated block must remain a recognized stopping event even when neither endpoint of the block is target-labelled. For even one-way optical sufficiency, every skipped forbidden event must remain excluded. Total return length and endpoint permutation alone do not certify either property.

The event concatenation rule is exact. If an admissible first block has length m and endpoint z_1 and a second block has length n, then

    E_combined = E_first union {(m+t,p,label):(t,p,label) in E_second},
    L_combined = m+n.

The event at the common endpoint appears in E_first; the second log excludes its time0, so no double-counting occurs. This formula uses the actual z_1 including sheet and direction. With data represented as subsets of a starting section, the second block's event predicates must first be pulled back under the actual first-block return map. Independently selected endpoint images cannot replace that pullback.

## 2. A precise rank restriction for pure block coarsening

Take any finite collection of actual consecutive same-direction blocks. Coarsen it by merging neighboring blocks, retaining all expanded flights and events and discarding none of their physical time. For every pair of positive integer roofs m,n, the merged roof is m+n. Therefore the total roof sum over the retained expanded itinerary is INVARIANT under this operation. It cannot be a strictly decreasing rank for a move that only coarsens that itinerary.

The number of represented blocks can decrease. That gives termination of finite section compression, not illumination: at termination the event log may still contain a forbidden corner or contain no target. This is a necessary terminal-base audit, not an assertion that every weighted Euclidean algorithm fails.

A Euclidean subtraction (m,n)->(m-n,n), m>n, does decrease m+n. To interpret it as an equivalent optical object one must identify where the removed n units live: e.g. an induced-return tower, a changed coordinate normalization, or a proved surface/path transformation. Simply declaring the shorter roofs to be physical travel times changes the flow. Inducing a subset, reparametrizing coordinates and deleting a trajectory segment are distinct operations; each needs its own exact reconstruction. No weight-independent bound is assumed.

## 3. Whole-surface affine transfer is a separate sufficient mechanism

Let F:M->M' be an actual invertible affine homeomorphism of connected translation surfaces, with a single constant derivative A in their translation charts. Suppose the reduced optical problem forbids Sigma', has source set X' and target set Y', and satisfies

    F(Sigma) subset Sigma',
    F^{-1}(X') subset X,
    F^{-1}(Y') subset Y.

Then EVERY legal straight X'-to-Y' path pulls back to a legal straight X-to-Y path: F^{-1} has the constant derivative A^{-1}, preserves positive traversal order, and a path avoiding Sigma' avoids F(Sigma). Its inverse endpoints belong to the actual original fibers by the stated inclusions. The complete physical unfolding equivalence then refolds it to a finite legal billiard path; corner and removable-corner marks remain correctly excluded. Nonemptiness and existence of the reduced path are separate requirements.

If F(Sigma)=Sigma', F(X)=X' and F(Y)=Y', this gives a bijection of legal connection paths. With stronger reduced forbidden sets, only the indicated one-way implication follows. Matching merely the projections of X',Y' to the base torus does not establish either endpoint inclusion. Preserving only genuine zeros does not establish forbidden-set inclusion when physical regular corner lifts were retained.

F need not descend to a polygon map. But if the induction calls M' the unfolding of a NEW room in the theorem class, the existence of that room, its actual marks and its wall/reflex count require an independent proof. A desired matrix or membership in SL2Z does not itself give F as a self-map of the original marked surface. The prior affine-lift theorem supplies appropriate powers fixing a finite covering fiber, not arbitrary shears fixing all physical endpoint fibers.

## 4. Which operation does what

- Same-direction induced return: expands to the SAME trajectories in M. It preserves their existence truth value but does not generate a new direction or prove that the chosen direction is illuminating.
- A change w->Bw on the same M: requires a separate relationship between the new and old flows. An integer arithmetic identity or graph edge does not supply it.
- A global F with derivative A: transports the entire path and its direction coherently, provided the exact endpoint/forbidden data above hold. Piecewise matrices on separate return blocks do not meet this condition unless their gluing is separately proved to give one constant-direction trajectory.

The square P_n calibration survives all three distinctions: arbitrary n may be present in weights or an affine matrix. No W-only bounded direction conclusion is extracted. The r9 dark control forbids a claimed all-arithmetic-surfaces positive terminal base; the theorem still needs an actual use of the physical original r<=8 hypothesis.

## 5. What is still required

These transfer conditions do not supply the author's weighted move, its well-founded rank, its availability, or an illuminated terminal base. In particular the sum-of-roofs diagnostic only rules out that stated rank for pure additive coarsening; it does not reject Euclidean induction with a correctly reconstructed tower or genuine global affine transport. No hypothetical author move is declared false before being stated. Endpoint-event exactness is a prerequisite encoding; the rank invariant is a small necessary restriction, not positive progress on the full illumination theorem.
