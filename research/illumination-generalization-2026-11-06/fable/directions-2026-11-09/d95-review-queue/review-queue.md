## How to read this

- **Status** uses three values. *Unreviewed*: no referee read it. *Gaps unfixed*: a
  referee found fixable gaps, and the live text doesn't show the fix. *Single impl*: a
  computation that only one implementation ran (coordinator reruns of the same code don't
  count).
- **Priority.** P1: a current-route result or a stated theorem depends on it. P2:
  supporting. P3: historical or superseded.
- **Theorem F.** It is a stated theorem, so its debts are P1 by the rule. RESULTS §5.1
  says the fold side isn't load-bearing for the working goal, so those rows rank last in
  P1.
- **Rank** is the order to work in. It weighs how many results lean on the item, then
  cost.
- Fix checks were done by grep on the live notes (2026-11-20, about 12:30).
