## Setup and notation

- P_Λ = R^2 / <2Λ, -1>, corners Λ/2Λ = {0, v, u, u+v}. Q = DR maps to P_Λ
  with degree n = m n_R, m = [Λ : Z^2]. CITED (d47 Defs 1.1-1.4).
- A certificate is a factor Q -> N -> P_Λ with δ = deg(Q -> N),
  d = deg(N -> P_Λ), n = δ d, z zeros and p poles of N. CITED (d10).
- Gauss-Bonnet gives p = z + 4. Fact L gives cycle lengths <= 3 over each
  corner, so each class j has p_j poles, z_j zeros, the rest 2-cycles.
  CITED (d10 Fact L).
- Each zero of N has δ reflex preimages, so δ z <= r. CITED (d10).
- V is the image of Z^2 in Λ/2Λ. For even m, |V| <= 2. If the 2-part of
  Λ/Z^2 is non-cyclic, |V| = 1. PROVED (Z^2 maps onto a subgroup generated by
  two elements of order <= 2 whose span has index m in Λ/2Λ's lift).
- Room vertices lie over V only, so zeros of N lie over V only. PROVED.
- Parity: w_j = p_j + 3 z_j satisfies w_j <= d, w_j ≡ d (mod 2), and
  Σ w_j = 4z + 4. PROVED (count of sheets over each class).

## 1. Lemma Z

**Statement.** A certificate with z >= 1 forces n <= 8r for Par, n <= 5r for
Rig, n <= 3r for Cut. A zero-free Cut forces n <= 4r + 4 and needs a
Λ-class whose Q-points are all vertices. **PROVED.**

Proof outline.
- Par at x: w_x = d, and Σ w_j = 4z + 4, so d <= 4z + 4 <= 8z. Then
  n = δ d <= 8 δ z <= 8r.
- Rig at x with identity class y: p_y = d, z_y = 0, so d <= z + 4 <= 5z and
  n <= 5r.
- Cut forces d = 3 (d10 remark at `../d10-mechanisms/theory.md:231`,
  re-derived here: the cut class needs a 3-cycle and a fixed point in one
  fibre of size d). Then n = 3 δ <= 3r with a zero.
- Zero-free Cut: the cut class is vertex-only, so its n preimages are
  convex or reflex corners; their count is at most conv + 3 refl = 4r + 4.

The d10 remark "Cut forces deg(N -> P') <= 3" is correct. PROVED.

**Refinement (Lemma Z').** At a target x outside V, or for Rig at a V target
with c_s != c_t, any certificate with a zero has n <= 4r. At r = 8 the
largest case is n = 32 with (δ, d, z) = (8, 4, 1). **PROVED** by the parity
constraints. The z = 1, d = 5 shape dies on parity, and z >= 2 gives
n <= 3r. Exact shape lists are in `shapes_exact.log` (arithmetic only).

## 2. Odd-part reduction

**Statement.** Let Λ ⊇ Z^2 + ZS + ZT. Put Λ' = Λ_(2) + M_0, where Λ_(2) is
the 2-primary part and M_0 = Z^2 + ZS + ZT. Then a certificate over P_Λ for
(S, T) transfers to one over P_Λ'. If S and T have dyadic coordinates,
[Λ' : Z^2] is a power of 2. **PROVED**, given the CITED Lemma 3.2 of d47
with the d48 correction: all four lifts S, T, ρS, ρT must lie in Λ', and
you compose prime-index steps one at a time.

Exact mark hypothesis: S, T ∈ Λ' and ρS, ρT ∈ Λ', where ρ is the deck
involution. With non-dyadic marks, the odd part of M_0 stays in Λ' and the
index is 2^k times an odd number fixed by the marks.

## 3. Zero-free certificates

- **Zero-free Par** depends on lattice data only: the classes of S, T, the
  lift pair, and Λ. PROVED (with z = 0, N is a pillowcase cover with p = 4,
  and B_x is determined by Λ-class data).
- **Lemma R0.** A zero-free Rig needs d = 4, no pole of N over a or over x,
  L = 2Λ, Λ ⊇ (1/2)Z^2, y = 0, and every vertex regular. PROVED. So liveness
  is irrelevant here, and the d48 non-live concern is moot.
  - Consequence: no zero-free Rig exists for lattice marks or at m = 2.
    PROVED.
  - The non-live bound [L : Z^2] n_R <= 4r + 4 also holds (PROVED), but the
    argument no longer needs it.
- **Zero-free Cut** needs a vertex-only Λ-class (Lemma Z). Classes outside V
  contain no vertex, so they're never vertex-only. PROVED.

## 4. Witness lemma

**Statement (whole lift pair).** For any lattice data (Λ, classes of S and
T, lift pair), some room with that data lights the lift pair. So no
certificate that depends only on lattice data separates all targets of a
lift pair. **PROVED.**

Witness room: the L-hexagon [-2K, 2K+1]^2 minus [2K, 2K+1]^2. Its vertex
(-2K, -2K) lies in 2Z^2, so a 2Z^2 translation puts a vertex at the origin
without changing the data. Even lift pairs use a direct segment. Odd lift
pairs use one bounce off y = -2K. Only integer vertices are needed. Marks sit
in the interior at the required classes; the front-back choice is the bounce
parity.

**Per-target version: FALSE.** Counterexample: Λ = (1/2)Z × Z, lattice S, T
with T_x - S_x odd. Then N = B separates at the V target in every room. So
the witness covers a lift pair as a whole, not each target. PROVED.

**Corollary.** Every lift pair with c_s = c_t has at least one non-V target.
PROVED (|V| <= 2 among 3 targets).

## 5. Bounds that remain

- **m = 2.** At a non-V target there's no zero-free certificate
  (sections 3-4). By Lemma Z', m n_R <= 4r, so n_R <= 2r <= 16. The same
  bound holds for c_s != c_t (Rig at a V target, Lemma Z'). PROVED.
- **m >= 4.** The witness lemma forces some target to use a certificate
  with a zero, so n <= 8r and n_R <= 8r / m <= 2r <= 16. PROVED.
- **Non-dyadic marks.** The odd index factor is at least 3 and lattice
  marks are excluded, so n_R <= 8r / 6 rounds to n_R <= 10 at r = 8.
  PROVED (arithmetic on Lemma Z with m >= 6).
