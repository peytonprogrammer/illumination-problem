Independent referee, 2026-11-14. Scope: the F\* statement, its derivation, the
allowed-area lists, and the filter code (`filter_rate.py`). I read d43, d38,
d36 (`astra.md`), d2-review, and `d2-factor-audit/audit.md` sections 1.1 to
1.7 and 3.1.

Computation, about 0.1 CPU seconds in total, one process, named rooms only:

- `check_fstar.py`, `check_fstar.log`: builds the fold monodromy from edge
  involutions with no shared code. It computes `B_x` as the congruence
  generated by the 2-cycles of `sigma_x`, checks the zero fibres of every

- `compare_filters.py`, `compare_filters.log`: compares d44's `passes()` with
  an independent F\* on every reflex-class vector for `r = 5..8` and

## 1. d2 applies to the join: CORRECT

d2's theorem (audit section 1.7, confirmed by d2-review): let `P` be a
strictly simple orthogonal lattice room with `r <= 8`. No lattice factor
`DP -> N -> PC` with the parity property separates two interior A points.
"Separates" means section 1.3's hypothesis: for one lift `S~`,
`phi(S~) != phi(T~)` for every lift `T~`. Hypotheses, checked against the
join `B_* = B_b v B_c v B_d`:

- **Lattice factor over the unit pillowcase.** A join of `G`-invariant
  partitions is `G`-invariant, so `DP / B_*` is an intermediate cover of
  `DP -> PC`. The check is over the unit pillowcase B, as d43 scopes it.
- **Parity property.** Section 3.1: a partition has it if and only if it
  contains `B_min`, the congruence generated by the 2-cycles of `sigma_X`
  for the three non-A classes. `B_x` is generated by the 2-cycles of
  `sigma_x` (d35.5, d38). So `B_*` contains the generators of `B_min` and
  contains `B_min`. A is the marks' class, and b, c, d are the other three.
- **Separation.** Under the Galois hypothesis, d36.3 makes `B_b`, `B_c`,
  `B_d` a chain, so `B_*` equals one of them. It separates all four lift
  pairs, which implies section 1.3's one-lift condition.
- **`N != PC`.** Separation implies it.
- **Interior marks, strictly simple, `r <= 8`.** These are in the check's
  scope. d2 needs no normalization (d2-review, "Hidden assumptions").
- **d36.3's own hypotheses.** d36.1 needs at least 4 cone points
  (`2r + 4`). d36.2 needs two interior lattice marks. A Galois `phi_x` lies in
  `Deck(DP/PC)`, because its deck maps commute with `psi`.

There is no gap. d2 is "PROVED" by hand in section 1.7, reworked by
d2-review, and backed by the computer-assisted `k <= 6` theorem. F\* inherits
that trust level.

## 2. Non-Galois implies `delta >= 3`: CORRECT

- `delta = 1`: `B_x` is discrete and `phi_x` is the identity, which is
  Galois. d36.3 allows it.
- `delta = 2`: an index-2 subgroup of the monodromy group is normal, so the
  cover is Galois.

So some `x` has `delta_x >= 3`. That `x` also has a separating `B_x`, so
`d >= 2`, and d36.4 applies to it. d36.4 needs at least 3 corner classes,
which is in scope.

## 3. Zero fibres and the `rho` inequality: CORRECT

- Each reflex corner of `P` lies on the seam. It has one lift in `DP`, a
  single zero of angle `3 pi`. So `DP` has exactly `r` zeros, one per reflex
  corner. There is no double count.
- Audit section 1.1: over a zero of `N`, every preimage has `e = 1` and is a
  zero. So a zero has exactly `delta` preimages, all reflex corners.
- The fold sends a lattice point `v` to the pillowcase corner `v mod 2`, and
  `pi_P = psi o phi`. All preimages of a zero over corner `y` therefore have
  parity class `y`. This holds by construction.
- Distinct zeros have disjoint fibres. So the number of zeros over `y` is at
  most `floor(rho_y / delta)`. Summing gives
  `z <= sum_y floor(rho_y / delta)`.
- Zeros may sit over any class, including x and A. F\* sums over all four,
  so it doesn't depend on that.
- `rho_y` uses absolute parity. Moving the origin permutes the classes, and
  the sum is permutation-invariant. So F\* is a per-room test that doesn't
  depend on the pair.
- `delta * z <= r` follows from the same count, and so does
  `z_min * delta <= r`.

Computed: every class quotient of the 22-wall room, P6, and the cross has
each zero fibre made of exactly `delta` 3-cycles. The bound is tight on both
dark rooms. In the 22-wall room, `rho = (0,3,3,3)` and `delta = 3`, so the sum
is 3, which equals `z = 3`. In P6, `rho = (4,4,0,4)` and `delta = 4`, so the
sum is 3, which equals `z = 3`.

## 4. `z_min` and allowed areas: CORRECT

d36.4 gives `d <= 4z + 1` for odd `d` and `d <= 4z` for even `d`. So
`z >= ceil((d-1)/4)` and `z >= ceil(d/4)`, as stated. `z * delta <= r` with
`delta >= 3` and `r <= 8` gives `z <= 2`, so `d <= 9`.

The recomputed lists match the README exactly (`compare_filters.log`):

| r | Allowed areas |
| --- | --- |
| 5 | 25 |
| 6 | 21, 24, 25, 27, 30 |
| 7 | 21, 24, 25, 27, 28, 30, 35 |
| 8 | 21, 24, 25, 27, 28, 30, 32, 35, 36, 40 |

The `n = 40` example is right: only `(delta, d) = (8, 5)` fits, so all 8
reflex corners lie in one class.

The code starts at `d = 3`. That is valid, because a zero needs `d >= 3`
(local degree 3 over a pillowcase corner). My version also allows `d = 2`. The
results are identical.

## 5. Implementation: CORRECT, one note

- `filter_rate.py` `cases`/`passes` match the statement. `zmin` is
  `(d+2)//4` for odd `d` and `(d+3)//4` for even `d`. `passes` has no `r`
  cap. Reflex corners are lattice points with exactly 3 of 4 cells.
- Over all reflex-class vectors with `r = 5..8` and `21 <= n <= 5r`,
  `passes` and my implementation give 0 mismatches.
- With the cap lifted:
  - 22-wall room (`n = 15`, `r = 9`) passes through `(delta, d, z_min) = (3, 5, 1)`.
  - P6 (`n = 20`, `r = 12`) passes through `(4, 5, 1)`.
  - The cross also passes.

  This agrees with `fstar_named.log`.
- `check_rooms.c` and `count_rooms.c` don't implement F\*. The production
  stage 2 is unwritten (README, "Open risks").

**Note for stage 2.** `rho_y` depends on the shape and the parity pattern,
but F\* also needs the room's actual area `n`. Stage 2 must apply `passes`
to each `(pattern, n)` pair. A per-pattern verdict must not be reused across
areas. Validate stage 2 against `passes()` on the 80,000 sample rooms and on
validation plan items 2 and 4.

## 6. Counterexample search: none

I checked each link for a room and pair that F\* would discard wrongly:

- **Positive implies separation.** A positive has every `B_x` separating all
  four lift pairs. That gives `d >= 2` for d36.4 and the section 1.3
  condition for d2.
- **The Galois branch.** d36.3 and d2 hold with no normalization and no area
  limit. A room in this branch has no positive at `r <= 8`. The 22-wall room
  and P6 are non-Galois, and both have `r >= 9`.
- **The non-Galois branch.** For that `x`, d36.4 and the fibre count give the
  F\* inequality. F\* takes the disjunction over all factorizations, so it
  doesn't need to know `x`.
- **Possible escapes.** A room escapes only outside the check's scope: at
  most 2 corner classes, wall or non-lattice marks, different-class marks,
  or relative certificates. d43 and the README already exclude those.

Residual trust: F\* is exactly as reliable as d2 section 1.7, d36.3, and
d36.4. Each has had one independent review.

## Required fix

None for the theory. For the code, stage 2 must evaluate F\* per area `n`
(see section 5) and be cross-checked against `filter_rate.passes`.
