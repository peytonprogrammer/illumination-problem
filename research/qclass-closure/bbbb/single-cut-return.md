# When a sealed-piece witness survives opening a portal

In the d163 cut decomposition, suppose a horizontal cut J separates a retained main piece from an attached orthogonal lattice piece. Both endpoints of the proposed shot lie in the main piece. There is a computable set of directions in which the sealed mirror on J can be replaced by a genuine excursion through the attachment, even if the main-piece path hits J repeatedly.

**Rectangular attachment.** For a width-u, depth-h rectangle attached across its whole width, let s=|v_x/v_y| with v_y≠0. In the doubled side coordinate of circumference 2u (position and horizontal velocity sign), a full excursion from J to the cap and back advances phase by 2hs. The cap contact occurs after phase advance hs. If hs is an integer multiple of u, an interior entry misses both cap corners, returns to the same point of J and has exactly the velocity produced by reflection on sealed J. This includes odd multiples: the cap height is on the opposite sheet but the return phase is unchanged. Conversely, for nonzero horizontal velocity a single complete corner-free excursion preserves the signed phase only if hs is an integer multiple of u. This concerns a full-width attachment; smaller mouths require checking intervening returns to the supporting wall.

**General attachment.** Cut its interior horizontally at every vertex level and the portal level. In each open band, each connected run is a rectangle with width uᵢ and height hᵢ. There are only finitely many ratios, all rational. Take any positive common multiple C of the rational numbers 2uᵢ/hᵢ, so C hᵢ/(2uᵢ) is an integer for every run. Suppose a corner-free shot in the sealed main piece has |v_x/v_y| an integer multiple of C. At every hit on J require its abscissa x to differ from the abscissas of all attachment vertices and from the cut endpoints. Then that shot lifts to a legal path in the open room, hitting the same target with the same final direction.

To prove this, begin at one of the specified entries. In a band traversed at slope s the unfolded horizontal travel is s hᵢ, a multiple of 2uᵢ. It exits at the same physical x with its original horizontal sign. Every vertical-wall reflection strictly inside the band is smooth. At a band boundary x is away from all vertex abscissas. Thus the ray either passes through that level or meets a smooth horizontal wall. It encounters these events in precisely the order of a vertical ray along the interior component at that x. This component starts at J and ends on a horizontal wall because the piece is bounded. After reflecting there, the same band argument applies in reverse vertical order. The ray returns through J at x, with horizontal sign preserved and vertical sign reversed. Concatenating this finite excursion at each J hit proves the assertion. A vertical shot itself works by the same column argument. A port endpoint excluded by this sufficient test might still be physically legal under the d160 germ rule.

**Named M3 replay.** In LLLLRLLLLRRR the cut (0,4)–(1,4) bounds a unit square. The sealed-main path (1/4,17/4) → (1/2,4) → (3/4,17/4) used in dent-cut-transfer.md has s=1. After opening the cut it first crosses (1/2,4), then reflects at (1,7/2), (1/2,3), (0,7/2), crosses (1/2,4) again and reaches (3/4,17/4). Thus its direction and endpoint survive, although its original physical word does not. The two marks are directly visible as well; this verifies the transfer rule rather than supplying an all-marks result.

**Limit.** The lemma transports an existing shot in a specified slope set. It gives no initial shot for arbitrary specified marks. Indeed for fixed S the countable resonant pencil reaches an area-zero subset of possible real targets: each directed trajectory up to its first corner is a countable union of finite line segments. The same observation does not rule out reaching particular lattice targets. Pairs on opposite sides of J also require an actual hit inside the excursion. No new all-length word is established. ## What is the smallest W ≤ 20 room this result doesn't cover?

A smallest OPEN ledger word is LLLRLLLRLR at W=10, with vertices (2,0), (4,0), (4,1), (3,1), (3,4), (0,4), (0,3), (1,3), (1,2), (2,2). Inside the selected two-direction OPEN group the first count is W=12. The named control LLLLRLLLLRRR has vertices (2,2), (2,0), (5,0), (5,1), (4,1), (4,5), (0,5), (0,3), (1,3), (1,4), (3,4), (3,2); the general all-length statement for this word remains open.
