## Preliminary check of the setup

- Each triangle has one A vertex, one mixed vertex and one odd-odd vertex, with angles π/4, π/2 and π/4.

## Lemma 1 — ACCEPT

**Angle identity.** A simple polygon has W corners and interior-angle sum (W−2)π, which is 4(W−2) in units of π/4. Every mixed and odd-odd vertex of every triangle in P is a corner. Each triangle therefore contributes 2 + 1 = 3 units at corners. A vertices contribute only when they are corners, which gives E_A. So 4(W_P−2) = 3N + E_A is correct, and reflex angles are handled correctly.

**Interior a.** The star at a contributes exactly two contiguous right-angle sectors at each axial mixed neighbor m = a ± e_i. That point is non-A and lies in P, so it must be a corner:
- two sectors would make it smooth, which is forbidden;
- four sectors would make it interior, which is forbidden;
- so it has exactly three sectors.

The extra triangles at the four neighbors are distinct, because each triangle has exactly one mixed vertex. None of them lies in the star. So N ≥ 12 from a alone.

**b interior.** The two stars are disjoint because each triangle has a unique A vertex. Then N ≥ 16, so 4(W−2) ≥ 48 and W ≥ 14. ✓

**b smooth.** Angle π at b means a contiguous half-star of 4 triangles.

The cleaner way to state the overlap argument is this. The extra triangle at m is one of the two triangles at m whose A vertex is 2m − a. It can lie in b's half-star only if b = 2m − a. The four values 2m − a = a ± 2e_i are distinct, so at most one requirement can be met by b's half-star. At most one triangle can serve that requirement, since two would fill all four sectors at m. This agrees with your common-neighbor argument.

So N ≥ 8 + 4 + 3 = 15, giving 4(W−2) ≥ 45, so W − 2 ≥ 12 and W ≥ 14. ✓

**Case coverage.** A noncorner A point is either interior or smooth, so the case split is complete. The corollary actually holds for W_P ≤ 13.

## Lemma 2 — ACCEPT

Let S be an interior lift of a, with S in copy i. Then g_i⁻¹(S) = f(S) = a. So every copy containing S has S at its smooth boundary point, and each contributes exactly angle π.

Copies not containing S are closed sets at positive distance from S. So a neighborhood of S is covered by the half-disks of the copies that contain S. Because their interiors are disjoint, there are exactly two copies, and they are complementary along the line g_i(l).

The mirror condition then forces g_j = R ∘ g_i. This also follows from coherence alone: g_j g_i⁻¹ fixes the shared segment pointwise, and it is not the identity because the interiors are disjoint.

**Disk argument.** This is correct. If x ∈ l ∩ int P, a disk D around x inside int P satisfies R_l(D) = D. Then D lies in int R_l(P) as well, so the interiors overlap.

**Supporting line.** int P is connected and avoids l, so it lies in one open half-plane. P is the closure of int P, so P lies in the corresponding closed half-plane. ✓

## Lemma 3 — ACCEPT

**Bound on W_P.** From 2(W_P − 4) + 4 ≤ 21 we get W_P ≤ 12. Lemma 1 then makes both marks smooth.

**Same reflection line.** With m = 2 and copies {P, g(P)}, each interior lift must lie in both copies. In P-coordinates, S = a and T = b.

Lemma 2's argument gives g = R_{l_a} as maps, and likewise g = R_{l_b}. Hence l_a = l_b. ✓

**The intersection K.** K ⊆ H ∩ H′ = l, so K ⊆ P ∩ l. For the reverse inclusion, note that R_l fixes l pointwise, so P ∩ l ⊆ R_l(P). Therefore K = P ∩ l. That reverse inclusion should be stated.

**Euler inclusion–exclusion.** This is valid because R_l preserves the tiling. P, R_l(P), Q and K are therefore all subcomplexes of one cell complex, and χ is additive on subcomplexes; Mayer–Vietoris gives the same result.

Each component of K is a closed interval or a point, so χ(K) = c. Q is a closed simple polygon, so χ(Q) = 1. Then 1 = 1 + 1 − c, so c = 1. Since a ≠ b, K is a nondegenerate interval containing [a, b]. ✓

**Angle π between a and b.** This needs one sentence of justification. Because int P ∩ l = ∅, we have K ⊆ ∂P. Since ∂P is a simple closed curve, near a point x of the open segment (a, b) the boundary arc is exactly that segment of l. P lies on one side of it, so the angle at x is π.

**The forbidden smooth point.** The open segment (a, b) contains a non-A lattice point:
- a mixed point if l is axial;
- an odd-odd point if l has slope ±1.

That point is a smooth point of P that is not A, which the parity-base condition forbids. ✓

The closing remark is correct. With m = 2, every possible contact is contained in K, and connectedness of K was derived, not assumed.
