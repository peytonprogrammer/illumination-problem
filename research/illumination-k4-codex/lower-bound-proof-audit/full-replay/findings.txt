What is independently checked
The frozen guard-checker.py is a copy of Codex's previously independently written persisted-replay/audit.py, not Opus's tracer or guard checker. It uses exact rational arithmetic. For each supplied segment it partitions at every canonical edge-line crossing and forces all triangles incident to interior crossings and interval midpoints. For each supplied bounce it verifies specular reflection in exactly one allowed wall direction, requires both adjacent path arms on the same wall side, requires every incident triangle on that side, and forbids every incident triangle on the opposite side. This makes the hit a smooth wall point and excludes true corners. Endpoint A stars are forced full. The required/forbidden sets must follow from the saved guard and those stars. If a forbidden tile belongs to an endpoint star, the guard premise is impossible and its implication is vacuously sound; this is reported explicitly. Whenever a generating room is present, its agreement with the guard and path is additionally checked.

The two path workers reuse those pure functions with bounded memoization caches. This changes memory use, not arithmetic or acceptance rules. Four malformed controls (wrong target, missing required tiles, missing forbidden tiles, invalid reflection) must be rejected before the library replay proceeds.

DRAT checks invoke the standard drat-trim binary independently on each saved final CNF/proof pair, requiring both successful exit and s VERIFIED. These are independent executions of an existing proof checker, not a separately implemented second proof checker. Neither a producer log nor an UNSAT solver status is accepted as the replay outcome.

Binding and interruption
manifest.json fixes each guard file hash and record count, each CNF/proof hash, both checker hashes, and the runner hash. Per-file guard checkpoints record the verified prefix count; a PASS requires the full expected count and a post-run input hash check. Existing checkpoints are reused only under the same input/checker/runner binding. Proof receipts record the precise CNF/proof/checker hashes and are saved only after replay and post-run hash verification. Guard and DRAT logs are separate, so the independent processes do not write the same log.

Limits
These replays do not independently prove the mathematical finite-case census, geometry necessity, arithmetic completeness or guard-to-clause transformation. Those have separate audits. Full replay does not enlarge the restricted theorem, establish universal 22-wall minimality or establish historical novelty.
