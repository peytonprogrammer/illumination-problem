# Verdict: **accept, scoped**

The exclusion holds as stated. In `parity-W25-24`, no real combination aβ0 + bβ1 with (a,b) ≠ 0 lies in the real span of the 40 saved axis core classes. This rests on two things: the pinned inputs being the reviewed period-derivative rows of parallel-transported classes in the same offset coordinates, and those entries being exact (see item 6). I found no gap in the mathematics or the code logic. I have only hardening suggestions, and none of them changes the conclusion. I checked everything by reading; I did not run anything.

## 1. Collar period formula with independent offsets: correct

- The flanks are wall 1, from (1,0) to (1,1), and wall 4, from (1,2) to (1,3). Both have inward normal (−1,0), which is consistent with counterclockwise vertex order.
- Under the convention n·x = c, the flank lines are x = −c1 and x = −c4. Let alpha run from p = (−c1, y_p) to q = (−c4, y_q).
- The b0 loop goes along alpha in sheet I, crosses into sheet V at q, goes back along alpha in sheet V, and re-enters sheet I at p. The V-sheet traversal develops to V(p − q) = −VΔ. So hol = Δ − VΔ = (2Δx, 0) = (2(c1 − c4), 0).
- Affine development gives the same result. Reflecting p across x = −c4 gives (−2c4 + c1, y_p), so the net displacement is (2(c1 − c4), 0). The reflection constants are exactly what carry c1 and c4. Dropping them would lose the formula, so the prose warning is right.
- Collinearity of the flanks is never used. The formula holds for all (c1, c4) near the base.
- **Sign convention:** if the stored convention were x = +c, the formula would flip sign. It would still be ∝ (e1 − e4) in the x-block, which is all the argument needs. The convention is immaterial.

## 2. D4 / quarter-turn transport: correct

The deck rotation r maps the sheets {g, gV} to {rg, rgV}, so hol(r·b0) = r·hol(b0). That gives:
- hol(b1) = (0, ±2(c1 − c4)), where the sign depends on orientation convention,
- hol(b2) = −hol(b0),
- hol(b3) = −hol(b1).

So hol(β0) = (4(c1 − c4), 0) and hol(β1) = (0, 4(c1 − c4)), up to that convention.

## 3. Separating functional: valid

- If β = Σλᵢγᵢ in H₁(X₀; ℝ), then Gauss–Manin transport over the small fixed-angle family gives hol(β_t) = Σλᵢ hol(γᵢ,t).
- Periods are affine-linear in offsets here, so the derivatives are exact constants.
- The test works whichever homology variant is meant: punctured, filled, or relative to the marks. Loops around regular marked points have zero holonomy, and the neck loops are absolute.
- Injectivity of the period map is correctly not needed.

**The deformation δ = e20 − e4 is legitimate.**
- Wall 4 shifts horizontally. Vertex 5 slides along wall 5, and the lengths of walls 3 and 5 change by O(ε).
- Wall 20 runs from (−1,3) to (−2,2) between the parallel horizontals y = 3 and y = 2. Its endpoints slide along walls 19 and 21, its own length is constant, and walls 19 and 21 stay positive.
- The two moved walls are not adjacent. Simplicity and interior marks persist by openness, and the marks are fixed (`delta[25:] == 0`).
- Plausibility check, my reading only and not needed for the proof: the band y ∈ (2,3) spans exactly from wall 20 to wall 4. With wall 20's inward normal (1,−1), δ shifts both band endpoints by the same amount. That makes column equality between walls 4 and 20 unsurprising for axis cores, which is a good sign that the data isn't accidental.

**Evaluation:**
- δ·(e1 − e4) = 0 − (−1) = 1, so d hol(b0)[δ] = (2, 0).
- The same δ placed in the y-block gives d hol(b1)[δ] = (0, 2).
- Therefore d hol(aβ0 + bβ1)[δ] = (4a, 4b) ≠ 0, while every axis-span element gives 0.

## 4. Checker: non-circular and correct

- The targets are hard-coded from the hand formula, not derived from the forms.
- δ is derived from the forms, but it is then re-asserted against all 80 rows directly.
- I traced both eliminations. Incremental reduction in increasing pivot order is valid: a row with pivot p is zero below p, so subtracting it cannot reintroduce earlier pivots. Reverse back-substitution correctly annihilates every basis row.
- When the residual is nonzero, `target·dual = residual[free] ≠ 0` holds automatically, so the `assert value` cannot falsely pass.
- The receipt is exactly −1 at index 4 and +1 at index 20, length 29 = 25 + 4. It reproduces neck x-derivative = 2.
- The minimal certificate is just three facts: the hash pins, `row[4] == row[20]` for all 80 rows, and the target being ∝ e1 − e4. The RREF and rank (20/10) machinery is redundant for the conclusion. The ranks are mutually consistent: 20 = 2·10, meaning the vector image is S⊕S. I can't verify the rank values by hand.

## 5. Plane claim: proved by the argument, not separately asserted by the code

The vector-RREF section rejects t0 and t1 individually. That alone does not exclude combinations of them. The plane claim actually follows from the scalar δ applied blockwise to both blocks, which is the hand argument in §3. The JSON field `neck_plane_axis_span_intersection` is justified, but by that reasoning rather than by a direct assertion.

## 6. Hardening suggestions (not gaps)

1. **Explicit plane assertion.** Assert that every vector form vanishes on both (δ, 0) and (0, δ). Also assert that t0 and t1 evaluate to (2, 0) and (0, 2) on them.
2. **Exactness of entries.** `F(x)` silently accepts JSON floats. Add `assert all(isinstance(x,(int,str)) ...)` so the "exact" claim can't rest on float coincidence.
3. **Index alignment.** Assert `len(c['offset_normals']) == c['walls'] == dim - 4`. This pins the shared indexing of normals and derivative columns, which is currently implicit.
4. **Optional convention pin.** Assert the stored c1 and c4 correspond to x = 1, to fix the sign. This is cosmetic, since the sign is irrelevant.

## Scope respected

This result says nothing about all-cylinder span or about actual-event detection. It also does not establish that the period map is injective. The stated consequence follows: any neck ⊂ C_flat proof must use non-axis cylinder classes or a different global argument.
