## §5: two-sided sign transfer

**Shear formulas.** The twist increments are combinations of core classes, and Q vanishes on those cores. So Q(gη) = v is unchanged, while the period w moves to Mⁿw.

- Horizontal shear: w′ = (p + naq, q), so det(w′, v) = p v_y − q v_x + naq v_y. This matches g_h,n.
- Vertical shear: w′ = (p, q + nbp), so det(w′, v) = p v_y − q v_x − nbp v_x. This matches g_v,n.
- Both shears have determinant 1, so σ is preserved.

**Odd seed.** Q ≡ (1,1) mod 2 and Q is an integer vector, so v_x and v_y are odd and hence nonzero. The slopes aqv_y (when q ≠ 0) and −bpv_x (when q = 0) are therefore nonzero, provided a, b ≠ 0. State that a, b ≠ 0 explicitly.

**Wall-parallel powers.** When q ≠ 0, w′ is wall-parallel only if p + naq ∈ {0, ±q}. That excludes at most three values of n. The q = 0 branch is the same. The claim is correct.

**Axis exceptions in the general paragraph.**
- If q v_y = 0 and p v_x = 0 with w, v ≠ 0, the only cases are w = (0,q) with v = (v_x,0), or w = (p,0) with v = (0,v_y). The case analysis is exhaustive.
- In the first case, one horizontal power n₀ ≠ 0 makes p′ = n₀aq ≠ 0, and then the vertical powers give slope −bp′v_x ≠ 0.
- The composite h^{n₀}vⁿ lies in the group, and v and σ are unchanged. So "at most one preliminary shear" is correct.
- Side remark: in both exceptional cases det(w, v) ≠ 0 already, so the seed itself has a nonzero row. Only the second sign needs the shear.

**Admissibility of the image events.** Images of events under the affine maps are straight. They keep the midpoint, the equal halves, singularity avoidance and the π-sector. The physical labels being fixed is still imported from `corner-rigidity.md`. That dependency is honestly stated.

**Required fix B (the compactness sentence).**
1. *"After quotienting the symmetries" is undefined.* The hypothesis "vector seed detection on the subspace" already excludes a common kernel, so the quotient is either unnecessary or a sign that detection only holds modulo some trivial directions. Either name those directions or delete the phrase.
   - The covering argument itself is right: the open sets {r_e > 0} cover the unit sphere, a finite subcover exists, and by Farkas these finitely many rows positively span the dual space.
2. *Multi-parameter opening.* The reviewed opening proposition is one-parameter. For a finite family on a k-dimensional subspace you need a radius that is uniform over directions. It is a one-line lemma:

   - So the signed area equals r_e(δ) + O(|δ|²) uniformly, and admissibility is an open condition.
   - On the compact set {r_e ≥ c|δ|} this gives a uniform ε.

   State it rather than relying on the one-parameter proposition.

## §7: binary full rank implies real detection

- **Per-pocket parity.**
  - The diagonal load of each pocket, (I−R)u_r, has both coordinates odd. For example, the anti-diagonal case gives (−1,−1).
  - The moving axis wall is perpendicular to u_r under rotations, so its load 2u_r is even.
  - The portal-line walls are fixed, and the corner term 2L_p v_c is even even when c is a vertex of pocket r.
  - So ∂Q/∂t_r ≡ B_er·(1,1) mod 2. This needs the stated hypothesis that the walls are distinct, so that each hit is charged to one parameter.
- **The minor argument.** The determinant is an integer polynomial, so reduction mod 2 commutes with it. A minor that is 1 over F₂ is therefore odd over ℤ, hence nonzero, so the real matrix has rank k and Mδ ≠ 0 for every real δ ≠ 0. This is correct.
- **The non-converse.** The note correctly says that failing the binary rank test does not imply failing real detection.
- **Wording.** "D4 rotations" should probably be "D4 images". A pocket reflected in the portal-normal axis is not a rotation of the original, and the argument covers it equally well.
- **Hypothesis to state.** The transfer to §5 needs every pocket slide to fix the continued axis-core periods in the k-pocket room. The local reason holds for any D4 image: axis rays entering the portal use the fixed vertical-line branch, DHD or its image. But the invariance is imported per pocket, so state it as a hypothesis on the k-pocket room.

## §8: copy colour and the topological bit

**Seam structure at the two endpoints.**
- The room angle at B₀ is 225°: the wall on x=1 below the portal plus the 45° pocket wedge. Its mirrors V and D generate D4. So there is one lift, with cone angle 8·5π/4 = 10π, and the seams alternate V and D, giving four D-seams.
- At A₀ the angle is 45°, generated by D and H. There is one lift with cone angle 2π and four D-seams.
- So D̂ is four arcs between two points, each of even degree. It is closed mod 2. ✓

**Strengthening worth adding.** Going once around either cone point crosses four D-seams, which is even. So the D-bit of a corner event does not depend on which side the path is pushed off the corner. The "selected π-sector" qualifier in §4 and §8 is harmless for the parity, though it still matters for (2).

**Case 1 (D is the only diagonal wall).**
- Colour changes exactly across the D-seams, so D̂ = ∂(colour-0 copies) mod 2.
- The bit of a path is the colour difference of its endpoint copies. Equivalently, the event's total linear part swaps the axes.
- X is connected. ✓

**Case 2 (another diagonal wall E exists).**
- If R_E = R_D, then R_D R_E = I.
- If R_E = −R_D, then R_D(−R_D)R_H R_V = (−I)(−I) = I.
- The interior arcs in the open disk cross no walls, so each loop meets D̂ exactly once. Intersection pairing then makes [D̂] ≠ 0. ✓
- The note correctly says these are continuous loops, not billiard words.

**Checker.**
- The colour assertions match the g ↦ gR_w convention. `colour` (a zero diagonal means swapped), Vlin, Hlin, Dlin and both loop products are correct.
- The self-invocation with `-O` exits at the top guard, so there is no recursion.
- Suggested addition: assert that (R_V R_D)⁴ = (R_D R_H)⁴ = I with each product's minimal period 4, and that D appears four times in each cyclic seam word. That checks the closedness of D̂ instead of only stating it.
