2. **Moving portal endpoints.** For "other cylinders", note that the moving portal endpoints B and C can change cylinder width and boundary saddle connections, but not core holonomy. The cores sit at positive distance from B and C.
3. **Corner-avoidance gap in the script.** The script checks only closed affine inequalities and never checks that segments avoid corners or marks. Record the hand check above, or add the three line-avoidance assertions.
4. **Strictness argument.** Strict interiority on the open rhombus follows from affinity. It holds because each inequality that is meant to be strict is not identically zero; the identically-zero ones are intentional equalities on D, H or a portal. State this.
5. **Non-uniform t-range.** The t-range shrinks with a. Only the t=0 derivative of the core is claimed, so this is harmless, but say so.
