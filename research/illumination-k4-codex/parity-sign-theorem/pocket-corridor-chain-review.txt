# Independent review of §34 (all-k moving-diagonal corridor family)

**Verdict: ACCEPT.** This accepts the scoped parametric theorem and the explicit raw family as a hand proof, subject to the corrections in §8. None of the corrections changes a displayed formula or a claim. The universal arbitrary-room pocket-detection goal stays **OPEN**.

I checked everything below by hand, with no tools. I did not rerun the k=2 script. I did not scan any room, ray, direction, word, cylinder, orbit or parameter. The k=2 control is treated as one consistency check, not as evidence for all k.

## 1. Lower-triangle D V D return (2/M < q < 1, M > 1): verified

Local frame at T. The cap is x ≥ 0, y ≤ −1, x − y ≤ 2. It has mirrors D₋: x − y = 2 and V₋: x = 0, and portal y = −1, 0 < x < 1.

| Leg | Velocity | Next hit | Duration | Interiority |
|---|---|---|---|---|
| 1 | (−1,−M) | D₋ at x = (Mq−1)/(M−1) | (1−q)/(M−1) | 0 < x < 1 ⇔ 1/M < q < 1 |
| 2 | (−M,−1) | V₋ at y = q − 1/M − 2 | (Mq−1)/(M(M−1)) | −2 < y < −1 ⇔ 1/M < q < 1+1/M |
| 3 | (M,−1) | D₋ at x = (Mq−1)/(M+1) | (q−1/M)/(M+1) | 0 < x < 1 holds |
| 4 | (−1,M) | portal at x = q − 2/M | (M+2−Mq)/(M(M+1)) | x > 0 ⇔ q > 2/M |

Checks:
- **Reflections.** D₋ sends (−1,−M) to (−M,−1). V₋ sends (−M,−1) to (M,−1). D₋ sends (M,−1) to (−1,M). All correct.
- **Durations.** Legs 1+2 sum to 1/M, and legs 3+4 sum to 1/M, so the total is 2/M. Correct.
- **Development.** D₋ V₋ D₋ is reflection in D₋(x=0), and D₋(x=0) is the line y = −2. Correct. The exit state equals that of a horizontal reflector at y = −2.
- **First-hit claims.** These need slightly more than "positivity" (see correction C2):
  - Leg 1 reaches D₋ before x = 0 because Mq > 1.
  - Leg 2 has x − y decreasing, so it moves away from D₋, and it reaches x = 0 above the vertex (0,−2).
  - Leg 3 has y decreasing and x − y increasing, so its only possible exit is D₋.
  - Leg 4 exits through the portal with x > 0.
- **Upper rectangle return.** x stays in [q − 2/M, q], which lies inside (0,1). Correct.

## 2. All-k cap entries and the alternating loop to ACTUAL T: verified

- **Hit times.** The unfolded height is y = 1 − Mt in the virtual strip [−2,2]. Far-wall hits occur at t_j = (4j+3)/M. Cap entries occur at (4j+2)/M with phase q_j = 1 − (4j+2)/M.
- **Number of hits.** The condition −2 − 4j > −4k gives j ≤ k − 1, so there are exactly k hits.
- **Phase bound.** The smallest phase is q_{k−1} = 3/(4k+1) = 3/M > 2/M. Equality to 3/M holds exactly at j = k − 1, so both cap lemmas apply at every return.
- **Arrival at T.** The path crosses y = 0 at t = (4j+1)/M with x = 1 − t. That is nonzero for j < k and zero only at j = k, t = 1. So the path arrives at the actual mark T at t = 1, with no earlier arrival.
- **Why D must be 4k.** The unfolded endpoint −4k folds to 0 in the period-8 strip. For D ≡ 2 (mod 4) the endpoint folds to ±2, so the path would hit the A corner at (D, ±2). The theorem therefore does not cover D ≡ 2 (mod 4) corridors (correction C5).
- **Corner avoidance.** Outside the caps, 0 < x_local < 1. The only point with x = 0 is the V₋ hit, whose y is strictly between −2 and −1. The (−1,−M) primitivity and lattice argument is also valid, because all mirrors are integer grid lines.

## 3. First-half corridor and primitive equal halves: verified

- **First half.** The segment (s·M, s) for 0 < s < 1 lies in (0, D+1) × (0, 1). Since gcd(M,1) = 1, it contains no lattice point. It has no ordinary hits.
- **Equal halves.** Both halves have speed √(M²+1) and duration 1.
- **Developed target.** The unfolded second half ends at (D, −D). Reflecting in x + y = D + 2 gives (2D+2, 2) = 2B. So B is the developed midpoint, and both halves equal (M, 1).

## 4. Moving diagonal π-continuation at B: verified

- **Link at B.** The upper rectangle contributes [π/2, π], the T star [π, 3π/2], and the pocket [3π/2, 7π/4]. Together they give 225°, contiguous.
- **Germs.** The source germ is π + α and the outgoing germ is 3π/2 − α, where α = atan(1/M) ≤ atan(1/5) < π/4.
- **Development across the flank.** Reflection across the ray at 7π/4 sends 3π/2 − α to 2π + α.
- **The sector.** [π+α, 2π+α] has length π. It contains 7π/4 exactly once and never reaches π/2. Its upper part lies in the adjacent copy [7π/4, 3π]. It embeds in the 8·(5π/4) = 10π cone. This matches §26.9 uniformly in M ≥ 5.

## 6. Raw fan-chain family membership and counts: verified independently

- **Triangle count:** 8(k+1) + 4k + k + (k+1) + (k+2) + 1 + 1 = 15k + 13.
- **Fans:** (k+1) + k + (3k+4) = 5k + 5.
- **Portals:** 3k+4 leaf portals plus 2k half-star portals = 5k + 4. The graph is a tree. Neighbouring unit boxes overlap only at the single point B.
- **B links:**
  - (4j+1, 1) for j ≤ k, and (4j+3, 1) for j < k: 225°.
  - (4j+1, −1) and (−1, −1): 135°.
  - (4j−1, −1) for j ≥ 1, and (−1, 1): 90°.
  - All are contiguous. None is 180° or 360°.
- **C links:** every C point is 270°, except (D+1, 2), which is 90°.
- **A points:** the only smooth boundary A points are the k half-star centres. (D, 2) is a 90° A corner. The interior integer points are exactly (4j, 0), all of type A.
- **Wall count by turning angle.** I counted the vertices independently instead of relying on the partial-charge identity:

  | Angle | Count |
  |---|---|
  | 225° | 2k + 1 |
  | 135° | k + 2 |
  | 90° | k + 3 |
  | 270° | 5k + 4 |
  | 45° | 3k + 3 |

  The turning sum Σ(180° − θ) = 360° holds identically in k. The vertex count is W = 12k + 13. This agrees with 2 + 6(k+1) + (6k+5), and gives W25 at k = 1 and W37 at k = 2.
- **Fit to the theorem's hypotheses.** k = 1 reproduces §26.9's coordinates and its path.
- **k=2 path.** I hand-checked the path: (9,1), (35/4, −5/4), (8, −4/3), (43/5, −7/5), (74/9, 2), (8, 0). The times 1/4 + 1/12 + 1/15 + 17/45 + 2/9 sum to 1, and q₀ = 7/9.

## 7. What the k2/W37 control does and does not establish

It is one consistent instance. It does not establish the theorem. The all-k proof rests on §§1–6 above.

## 8. Required corrections (editorial; no claim changes)

- **C1. Persistence for small t.** State in §34 what §26.9 states: every ordinary hit satisfies strict open inequalities (§1, and q_j ≥ 3/M), so the fixed word and the corner-free halves persist for small |t|. The opening step uses the §3 criterion conditionally.
- **C2. First-hit comparisons.** Replace "Positivity and the displayed coordinates prove…" with the four first-hit comparisons from §1. Positivity of durations alone does not order the hits.
- **C3. Vacuous parity block.** In the script, the assertion `parity*2*far == -4` reduces to −4·parity² = −4, a tautology. Delete it, or replace it with a real check of F_k(y) = (−1)^k·y − 4k, for example by composing reflections in y = −2, −6, … symbolically. Do not call it an "induction step".
- **C4. Certificate wording.** The geometry certificate says "two interior A points" but lists three for k = 2. In general there are k + 1. Confirm that the checker's string only means the marked points are interior A. Then state explicitly that extra interior A full stars are allowed by §1; the 6(k+1) term already assumes this.
- **C5. Scope remark.** Add that D ≡ 2 (mod 4) fails because the path would hit the corner (D, ±2). Such corridors, together with other cap shapes, LEFT-portal lower leaves, lower-pointing pockets and disconnected-H placements, remain open.
- **C6. Leaf names.** The leaves at (4j+2, 2) and (4j, 2) are the same orientation, fan start 6 with count 1. Call both "lower-right (right-portal)". §26.9 calls the (D, 2) square the "upper-right quadrant" (relative to B), while §34 calls it "lower-right" (relative to its A). Unify these.
- **C7. a_D for this pocket.** Note a_D = (1,1) for this u = (0,+1) pocket, to avoid confusion with §3's table.
- **C8. Hard-coded determinant.** The output field `determinant` is hard-coded as −(4k+2). Emit the computed det instead, which the script already asserts.
- **C9. Status line.** Change it to: "focused independent review accepts the scoped all-k hand proof with corrections C1–C8; universal pocket detection OPEN."

**Bottom line:** §34 is accepted as a specified infinite family with no wall-count bound. It does not prove the universal lemma, because arbitrary raw rooms need not contain this corridor-and-caps geometry.
