# Frozen seed provenance audit

[in progress] Universal actual endpoint seed existence remains open.

The nine saved seed orbits in the control are a rank-selected packet,
not an analytic construction. This follows directly from seed-module.py
and its fixed-room selection input. Reading34existing event packets adds
no new path, direction, word, room or orbit.

Six different exact marked pairs occur. The16rooms passing only the
literal-three-vertex filter split into four marked-pair groups (see JSON
for actual counts). A common event in a finite packet, if any, is only
sample evidence; an empty intersection proves neither event absence nor
failure of a construction outside the saved direction bound. The filter
itself does not certify the straight wall attachment on both sides.

The audit therefore supplies no universal seed theorem. Next proof work
must retain the actual marked pair and verify angular adjacency, rather
than extrapolate the control's greedy rank selection.
