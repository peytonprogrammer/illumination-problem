## Exact darkness proof

Reflecting across horizontal and vertical walls unfolds the room into four
orientation sheets, independently reconstructed as 60 unit squares. Each square
has a right neighbor r, an upper neighbor u, and a lower-left corner label:
source S, target T, forbidden corner B, or clear regular point.

All developed target lifts have integer coordinates relative to a source lift.
Consequently any connecting path has primitive integer direction (p,q). An
integral determinant-one coordinate change maps this direction to horizontal.
The square-tiled surface changes by elementary shears, whose permutation actions
are (r,u)->(r,u r^-1) and (r,u)->(r u^-1,u), and their inverses.

The vertex equivalence relation is generated by u r(i)~r u(i). Under each shear
the same relations are merely reindexed, so lower-left vertex labels remain
consistent. Horizontal travel follows successive r neighbors, stopping at B;
all S-labelled sectors must fail to reach T first.

Thus a finite supplied set of labelled states is sufficient if:

1. It contains the independently reconstructed initial surface, up to square
   renumbering.
2. It is closed under both elementary shears and their inverses, up to square
   renumbering.
3. Every state has no horizontal source-to-target connection before a blocker.

Induction then covers every word in SL(2,Z), hence every possible connecting
direction. No bound on directions or reflections appears in this proof.
The certificate need not be exactly the reachable orbit: a closed superset
suffices. Conversely, a list missing closure cannot justify a negative verdict.

`closed-orbit-audit.py` implements these checks independently. It uses a different
rooted graph encoding from the peer, imports only the Codex physical geometry
builder, and never generates or enqueues an orbit. It accepts supplied states as
`{"states":[{"r":[...],"u":[...],"label":"..."},...]}` or under
`components[*].states`. Run:

    .context/illumination-venv/bin/python -B \
      .context/illumination-k4-codex/closed-orbit-audit.py <certificate.json>

Claude reports 2,592 states in each of the two formal D4 components. For this
rectilinear room, the physical reflection group has four orientations; our own
single 60-square unfolding covers all physical initial directions. A matching
closed component is sufficient. The second formal D4 component comes from
adding diagonal reflection orientations absent from the room's mirror group.
