## Correction: the open-family paragraph

Parameterize the family by a = θ_s ∈ (1/8, 3/16) and d = θ_t ∈ (5/16, 7/16). Then:
- s = (12a, 16a)
- t = (12d, 8 − 16d) ≡ (12d, −16d) mod 2

The midpoint condition is 12(a ± d) ∈ 2Z and 16(a ± d′) ∈ 2Z, with the signs chosen independently per coordinate. Working through the cases:

- **Same sign "+" in both coordinates:** a + d ∈ ½Z. The family has a + d ∈ (7/16, 5/8), which contains ½.
- **Same sign "−":** a − d ∈ ½Z, which is impossible in the family.
- **Mixed, x "+" and y "−":** the only solution is a = 1/8, d = 3/8. That is the old positive control, which sits on the boundary of the family and is excluded.
- **Mixed, x "−" and y "+":** the only solution is a = 1/6, d = 1/3, which already lies on a + d = ½.

So within the family, the midpoint locus is the entire segment **θ_s + θ_t = ½**. It is a codimension-one line, not a set of isolated points.

Consequences:

1. **Replace "isolated midpoint equalities"** with: "midpoint equalities occur only on the closed nowhere-dense line θ_s + θ_t = ½. Its complement is an open dense set of separated, midpoint-free marks." The logical conclusion is unchanged.
2. **The family control (1/6, 1/3) satisfies the midpoint relation.** Here s = (2, 8/3) and t = (4, 8/3): x gives 2 + 4 ≡ 0 and y gives 8/3 − 8/3 = 0. The checker never tests midpoints on the nine family pairs, so `PASS` does not certify them as midpoint-free. Either relabel the nine as separation-only controls, or add a per-pair midpoint flag. With that flag, (1/6, 1/3) would read `true` and the other eight `false`. I computed a + d for each of the other eight; none equals ½ or meets the mixed-sign conditions.

## Scope

The scope statement is correct. Both pairs are globally lit, so this refutes only the claim that local central-cylinder separation plus physical wall realization forces a midpoint. It says nothing about the globally-essential-blocker conjecture.
