Bounded optical procedure
Each SAT model is independently reconstructed into maximal orthogonal walls with a single boundary, no point pinches/holes, actual full-A support, W<=20, k==7 and N<=42. An optical subprocess checks the direct slope then primitive directions with components between-4 and4, up to200reflections each. Short-ray failure means only that the filter did not find a path.
The fallback reuses the accepted labeled-origami shear/canonicalization formulas with frame labels and BFS direction extraction, capped at20000discovered states and the remaining per-room time. Every extracted direction is traced back against the actual physical polygon and the resulting finite path is independently replayed before LIT. A state/time/reflection extraction limit remains UNDECIDED. Only a fully exhausted orbit would trigger a second DFS decider check and a CANDIDATE_DARK status requiring review; this branch was NOT reached in the pilot.
Both cutoff handling and candidate-dark handling are implemented but no cutoff/dark output occurred during this successful run. Existing origami-decider-review/findings.md supplies the core finite-orbit justification and its implementation limits. This turn does not formally reprove the entire builder.

Sufficient optical clauses
For a verified path, guards.py cuts every leg at its integer horizontal/vertical grid crossings. All unit squares touching the interior sample intervals and crossing points are required present. At each smooth bounce all touching squares on the actual interior side are required present and all touching squares on the exterior side are required absent. Source/target full stars are already forced.
These whole-unit requirements are converted mechanically to canonical triangle U/Z conditions. inputs/guard_check.py is a function-only AST extraction of the separately authored guard_audit.py; its original library reads, sampling and CLI code are omitted. It checks the complete straight segments, crossing points, all bounce neighborhoods, straight-wall germ and reflection law independently of the unit-square derivation. Only a passing guard is translated into a clause. A square variable is represented by either of its equated triangle variables. Out-of-universe absent cells are automatically absent and need no literal. All required cells must be in the universe. Each added clause is verified to exclude the current model.
Every clause is justified for all completions matching its required/absent cells, not merely the room that produced it. Guard reuse affects enumeration order: the30rooms are not a uniform/random sample of the case.
