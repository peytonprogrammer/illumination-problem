# Three-star surplus-four illumination

[Read the PDF](manuscript.pdf) · [LaTeX source](manuscript.tex) · [Manuscript catalog](../README.md)

Working draft v0.1, November 6, 2026. Fixed three-star support, surplus four, at most 21 walls and six transparent points; connection within 32 reflections. Optical cases depend on archived certificates.

These are byte-for-byte copies of the [archived PDF](../../research/claude-illumination-check/triangle-preprint/triangle-preprint.pdf) and [source](../../research/claude-illumination-check/triangle-preprint/triangle-preprint.tex). The file manifests and import provenance record the source paths and SHA-256 values.

## Build

From this directory, run a LaTeX engine with the packages listed in the source, for example:

```sh
pdflatex manuscript.tex
pdflatex manuscript.tex
```

Record the source and PDF hashes in the import provenance after rebuilding.
